# JUSTSTEER FINAL SYSTEM EVIDENCE

## 1. System Architecture

JustSteer implements a dynamic, multi-stop routing architecture driven by edge-level machine learning models. 

**Flow:**
Context Data → FeatureResolver → OSM Structural Enrichment → ML Providers → PredictionOrchestrator → WeightCalculator → EdgeCostStore → A* Routing Engine → MultiStopRouter → FastAPI → React + Leaflet UI.

No architectural deviation has occurred. The system preserves request isolation via `RoutingContext` and `EdgeCostStore`.

## 2. Data Sources

- **OSM Road Network Structure (REAL):** The topological graph and structural attributes (e.g. `highway` classification, max speeds) are derived from genuine OpenStreetMap data (`chennai_drive.graphml`).
- **Contextual Traffic (REAL):** The training features utilize real contextual observations (e.g. weather conditions, temporal dimensions).
- **Road Safety Data (SYNTHETIC):** The safety risk training dataset is completely synthetic and is strictly used to validate the mathematical combination of costs.

**Truthful Limitation:** The system does NOT claim that historical traffic sensors cover the entire Chennai graph, nor does it claim that every road has historical traffic observations.

## 4. OSM Structural Enrichment

This successfully restores spatial variance and edge differentiation without fabricating impossible sensor-to-edge mappings.
